## 一、系统概述

### 1.1 系统简介

林夕置业酒店经营日报管理系统（以下简称"本系统"）是面向林夕置业旗下酒店门店的**经营数据管理平台**，实现门店每日经营数据在线填报、总部实时监管、投资者便捷查看、自动化报表分析等功能。

### 1.2 系统地址

| 环境 | 地址 |
|------|------|
| 生产环境 | http://82.156.225.171 |
| 本地测试 | http://localhost:3000 |

> 推荐使用 Chrome 或 Edge 浏览器访问。

### 1.3 账号说明

| 账号类型 | 说明 | 初始密码 |
|---------|------|---------|
| 系统管理员 | 由技术团队管理，不参与日常业务 | — |
| CEO账号 | 总部管理层查看全部数据 | 联系管理员获取 |
| 门店店长 | 每个门店一个店长账号 | `123456` |
| 门店员工 | 协助填报的店员账号 | `123456` |
| 投资人 | 查看投资门店数据（只读） | `123456` |

> ⚠️ 首次登录后请立即修改密码。如忘记密码，请联系系统管理员重置。

### 1.4 系统角色速览

| 角色 | 能做什么 | 不能做什么 |
|------|---------|-----------|
| **CEO/总部** | 看全部数据、审核日报、经营分析 | 不能管理系统配置 |
| **店长** | 填报日报、看本店数据 | 不能看其他门店数据 |
| **店员** | 协助填报日报、看本店数据 | 不能修改门店信息 |
| **投资人** | 看投资门店的经营数据 | 不能填报、不能修改任何数据 |
| **管理员** | 管理用户、角色、门店、模板等 | 不参与日常业务 |

## 二、快速入门

### 2.1 登录系统

1. 打开浏览器，访问系统地址
2. 输入**用户名**（或手机号）和**密码**
3. 点击「登录」按钮
4. 登录成功后进入首页工作台

![登录页示意](登录页：蓝色背景 + 居中白色卡片 + 用户名密码输入框 + 登录按钮)

### 2.2 退出系统

点击右上角用户头像/姓名 → 选择「退出登录」。

### 2.3 密码规则

- 初次登录默认密码为 `123456`
- 密码由管理员统一管理，如需修改请联系管理员
- 连续5次输错密码将锁定10分钟

### 2.4 界面布局说明

登录后的主界面分为三个区域：

```
┌──────────────────────────────────────────┐
│  左侧菜单栏  │  顶部栏（系统标题+用户信息）    │
│  · 工作台    │───────────────────────│
│  · 门店管理  │                      │
│  · 日报管理  │    内容区域            │
│  · 日报审核  │    （显示当前页面内容）   │
│  · 经营分析  │                      │
```

- **左侧菜单栏**：深色背景，显示当前角色可访问的菜单
- **顶部栏**：左侧显示系统名称，右侧显示站内消息铃铛和用户信息
- **内容区域**：灰色背景，显示当前页面的具体内容

## 三、CEO/总部管理层操作指南

> **适用角色**：CEO、总部经营管理人员  
> **核心场景**：查看全部门店经营数据、审核日报、经营分析决策

### 3.1 首页工作台（总部看板）

登录后默认进入总部看板，可一览全部门店当日经营概况。

**操作步骤**：

1. 进入系统后自动显示总部看板（如不在，点击左侧菜单「工作台」）
2. 顶部筛选栏可以：
   - 选择**基准日期**（默认今天）
   - 选择**门店范围**（默认全部门店，可多选特定门店）
   - 点击**快捷按钮**：今天 / 本周 / 本月
   - 点击**查询**按钮刷新数据

**看板内容解读**：

| 区域 | 显示内容 | 怎么看 |
|------|---------|--------|
| **统计卡片**（8个） | 应填报门店数、已填报、未填报、总营收、总间夜、均出租率、均ADR、均RevPAR | 数字越大越好（未填报越少越好） |
| **趋势对比图**（6个） | 营收/出租率/ADR/RevPAR/间夜/填报率 | 支持天/周/月切换，实线=当期，虚线=去年同期 |
| **门店排名** | 营收排名、出租率排名 | 谁好谁差一目了然 |
| **未填报列表** | 还有哪些门店未填报今日日报 | 需要跟进催报 |

### 3.2 门店管理

查看和管理各门店基本信息。

**操作路径**：左侧菜单 → 门店管理 → 门店列表

**可以做什么**：

- **查看门店列表**：表格展示所有门店，可按名称/城市搜索
- **查看门店人员**：点击门店行的「查看团队」按钮，弹窗显示该门店关联的用户
- **查看门店详情**：点击门店名称查看详细信息

> 注：CEO 不能新增/编辑/删除门店，这些操作由系统管理员执行。

### 3.3 日报管理

查看各门店日报填报情况的综合入口。

**操作路径**：左侧菜单 → 日报管理 → 日报管理

日报管理页面整合了日报的**填报、查询、管理**三大功能，CEO可以在此查看任意门店的日报列表和详情。

**操作步骤**：

1. 选择门店（下拉框多选）
2. 选择日期范围
3. 选择日报状态：全部 / 草稿 / 已提交 / 已锁定
4. 点击「查询」查看日报列表
5. 点击某条日报可展开查看详细数据

### 3.4 日报审核

对门店提交的日报进行审核。

**操作路径**：左侧菜单 → 日报审核

**审核流程**：

```
门店填报 → 提交 → CEO审核 → 通过（锁定）/ 退回（门店修改）
```

**操作步骤**：

1. 在审核列表中选择待审核的日报
2. 查看日报详细数据，核对：房量、间夜、营收、出租率等关键数据
3. 审核决策：
   - **审核通过** → 日报锁定，门店不可再修改
   - **审核退回** → 填写退回原因，门店需重新填报

### 3.5 未填报统计

查看哪些门店当天还未填报日报。

**操作路径**：左侧菜单 → 未填报统计

页面会列出截至当前，当天应该填报但尚未提交日报的门店列表，方便催报。

### 3.6 经营分析

**这是CEO最重要的决策支撑模块**，包含6个子页面。

#### 3.6.1 总部看板

同首页工作台，参见 [3.1 节](#31-首页工作台总部看板)。

#### 3.6.2 门店日报表

**操作路径**：左侧菜单 → 经营分析 → 门店日报表

功能：按日期和门店筛选，以表格形式展示每日经营明细数据，包含房量/间夜/营收/出租率/ADR/RevPAR等全部指标。

**操作步骤**：

1. 选择日期
2. 选择门店（可多选）
3. 点击「查询」
4. 查看表格数据或导出Excel

#### 3.6.3 门店月报表

**操作路径**：左侧菜单 → 经营分析 → 门店月报表

功能：以月度为单位，展示各门店月度汇总数据，便于月度经营分析和对比。

**操作步骤**：

1. 选择月份
2. 选择门店
3. 查看月度汇总表（加权平均ADR/RevPAR）
4. 支持导出Excel

#### 3.6.4 渠道分析

**操作路径**：左侧菜单 → 经营分析 → 渠道分析

功能：分析各门店的客源渠道分布（如OTA、Walk-in、协议客户等），了解不同渠道的贡献。

**操作步骤**：

1. 选择日期范围
2. 选择门店
3. 查看渠道分布饼图和表格
4. 点击「查询」刷新数据

#### 3.6.5 门店排名

**操作路径**：左侧菜单 → 经营分析 → 门店排名

功能：按不同维度对各门店进行排名对比。

**排名维度**：
- 营收排名
- 出租率排名
- ADR排名
- RevPAR排名

**操作步骤**：

1. 选择时间维度（日/周/月）
2. 选择排名维度
3. 查看排名柱状图和数据表

#### 3.6.6 经营趋势

**操作路径**：左侧菜单 → 经营分析 → 经营趋势

功能：查看单个门店或汇总的长期经营趋势。

**操作步骤**：

1. 选择日期范围
2. 选择门店（可多选对比）
3. 选择指标（营收/出租率/ADR/RevPAR/间夜）
4. 选择时间粒度（日/周/月）
5. 查看趋势折线图（支持多门店叠加对比）

### 3.7 投资人管理

**操作路径**：左侧菜单 → 投资人管理 → 投资人列表

查看投资人列表及投资门店关系。CEO可以查看投资人列表，了解各投资人对门店的投资情况。

## 四、门店店长操作指南

> **适用角色**：各酒店门店店长  
> **核心场景**：每日填报日报、查看本店经营数据、跟进经营状况

### 4.1 首页工作台（店长视图）

登录后进入店长专属首页，快速了解本店今日情况。

**显示内容**：

| 区域 | 说明 |
|------|------|
| 今日填报状态 | 显示今天是否已提交日报，未提交则显示「立即填报」按钮 |
| 本月统计卡片 | 本月累计营收、间夜数、平均出租率、ADR |
| 7日趋势图 | 最近7天本店经营趋势折线图 |
| 快捷入口 | 日报填报、历史日报 |

### 4.2 日报填报（核心操作）

这是店长**每天最重要**的操作。

**操作路径**：首页点击「立即填报」或左侧菜单 → 日报管理 → 日报管理 → 填报

**填报步骤**：

1. **进入填报页面**：自动显示今天的日期和本店信息
2. **填写基础数据**：
   - 可售房量（本店可供出租的房间总数）
   - 出租间夜数（实际出租的房间×夜数）
3. **填写经营数据**：
   - 客房营收（含早收入等）
   - 出租率（系统自动计算：出租间夜÷可售房量，也可手动输入）
   - ADR（平均房价，系统自动计算：营收÷出租间夜）
   - RevPAR（每间可售房收入，系统自动计算）
4. **填写渠道数据**：
   - 各渠道间夜数（OTA、Walk-in、协议客户、会员等）
5. **填写扫码数据**：
   - 扫码间夜数、扫码营收
6. **填写好评数据**：
   - 各渠道好评数
7. **填写评分数据**（如有）：
   - 各平台评分
8. **保存草稿**：可以中途保存，下次继续编辑
9. **提交审核**：确认无误后点击「提交」，日报进入待审核状态

**注意事项**：

- ⚠️ 系统会根据当前门店的**自有房量**自动带出可售房量，请核实后填报
- ⚠️ 出租率如果 > 100%，系统会提示异常
- ⚠️ 提交后日报状态变为「已提交」，需等待 CEO 审核
- ⚠️ 如果审核退回，需要修改后重新提交

### 4.3 查看历史日报

**操作路径**：日报管理页面，选择日期范围后查询

可以查看本店的历史日报记录，包括草稿、已提交、已锁定、已退回各种状态。

### 4.4 查看本店经营数据

店长可以通过经营分析模块查看本店的报表（与CEO相同，但**只能看到自己的门店数据**）。

**可查看的报表**：
- 门店日报表（本店）
- 门店月报表（本店）
- 渠道分析（本店）
- 经营趋势（本店）

## 六、投资人操作指南

> **适用角色**：各门店投资人/股东  
> **核心场景**：查看投资门店的经营数据，了解投资回报情况

### 6.1 首页工作台（投资人视图）

登录后进入投资人专属首页。

**显示内容**：

| 区域 | 说明 |
|------|------|
| 投资门店列表 | 显示您投资的所有门店，含：门店名称、城市、今日营收、本月累计营收、今日出租率 |
| 趋势图 | 点击门店行的「查看趋势」按钮，查看该门店的经营趋势图 |
| 快捷入口 | 进入经营分析查看更详细的报表 |

### 6.2 查看经营报表

投资人可以查看投资门店的经营报表（**只读，不可修改**）。

**操作路径**：左侧菜单 → 经营分析 → 选择相应报表

**可查看的报表**：
- 总部看板（仅显示投资门店数据）
- 门店日报表
- 门店月报表
- 渠道分析
- 门店排名
- 经营趋势

**数据隔离说明**：
- 投资人 A 投资了门店1和门店2 → 只能看到门店1和门店2的数据
- 数据为只读，不能进行任何修改、填报或审核操作

### 6.3 查看投资人列表

**操作路径**：左侧菜单 → 投资人管理 → 投资人列表

投资人可以查看投资人列表（只读），了解其他投资人的基本信息。

## 七、系统管理员操作指南

> **适用角色**：超级管理员（SUPER_ADMIN）  
> **核心场景**：系统初始化、用户管理、权限配置、模板维护、系统监控

### 7.1 用户管理

**操作路径**：左侧菜单 → 系统管理 → 用户管理

**功能清单**：

| 操作 | 说明 |
|------|------|
| 新增用户 | 填写姓名、手机号、用户类型、选择角色和门店后创建 |
| 编辑用户 | 修改用户信息、角色分配、门店关联 |
| 删除用户 | 逻辑删除（不可恢复，请谨慎操作） |
| 重置密码 | 将用户密码重置为 `123456` |
| 启用/禁用 | 切换用户账号状态 |
| 分配角色 | 为用户勾选一个或多个角色 |
| 分配门店 | 为用户勾选一个或多个门店（控制数据可见范围） |

**新增用户步骤**：

1. 点击「新增用户」按钮
2. 填写：
   - **姓名**：用户真实姓名
   - **手机号**：作为登录用户名
   - **用户类型**：管理员(1) / 门店用户(2) / 投资人(3)
   - **角色**：勾选对应用户类型的角色
   - **所属门店**：勾选用户需要访问的门店（门店用户必选）
3. 点击「确定」

### 7.2 角色管理

**操作路径**：左侧菜单 → 系统管理 → 角色管理

管理系统中的角色定义，一般情况下**不需要修改**。

**预置角色**：

| 角色 | 编码 | 说明 |
|------|------|------|
| 超级管理员 | SUPER_ADMIN | 系统最高权限 |
| CEO | CEO | 总部管理层 |
| 区域管理 | REGION_MANAGER | 区域运营管理（暂未使用） |
| 门店店长 | STORE_MANAGER | 门店负责人 |
| 门店员工 | STORE_STAFF | 门店协助人员 |
| 投资者 | INVESTOR | 门店投资人 |

### 7.3 菜单权限管理

**操作路径**：左侧菜单 → 系统管理 → 菜单管理

管理左侧菜单的结构和权限配置，**仅技术人员可操作，一般不需要修改**。

### 7.4 门店管理

**操作路径**：左侧菜单 → 门店管理

系统管理员可以执行门店的增删改查操作。

**新增门店步骤**：

1. 点击「新增门店」按钮
2. 填写门店信息：
   - **门店编码**：城市拼音首字母 + 3位序号（如 SZ001），创建后不可修改
   - **门店名称**：全称
   - **门店简称**：日常使用的简写名称
   - **城市**：所在城市
   - **区域**：所属经营区域
   - **自有房量**：门店自有房间总数
   - **店长**：选择关联的店长用户
   - **联系电话**：门店联系电话
3. 点击「确定」

**编辑门店**：点击编辑按钮修改门店信息（编码不可修改）。

**删除门店**：点击删除按钮。系统会检查该门店是否有关联数据（日报/用户/投资人），如有则拒绝删除。

**查看团队**：点击「查看团队」按钮，弹窗显示该门店关联的所有用户列表。

### 7.5 日报模板管理

**操作路径**：左侧菜单 → 系统管理 → 日报模板

管理日报填报使用的模板，控制各门店的日报填报字段。

**功能**：

- **新增模板**：创建新的日报模板
- **编辑模板**：修改模板名称和包含的字段
- **删除模板**：删除不再使用的模板
- **关联门店**：为模板指定适用的门店

### 7.6 字段配置

**操作路径**：左侧菜单 → 系统管理 → 字段配置

管理日报填报字段的定义，包括字段名称、显示顺序、是否必填、输入类型等。

> ⚠️ 字段配置直接影响日报填报界面，非必要不修改。

## 八、常见问题

### Q1：忘记密码怎么办？

联系系统管理员重置密码，重置后密码为 `123456`，登录后请及时修改。

### Q2：登录时提示"账号已锁定"？

连续输错密码5次会锁定10分钟，等待10分钟后再试。如需立即解锁，联系管理员。

### Q3：登录后看不到某些菜单？

不同角色看到的菜单不同。例如店长看不到「系统管理」菜单是正常的。

如果认为自己应该有某个菜单的权限，请联系管理员检查角色权限配置。

### Q4：日报填报时，出租率显示大于100%？

系统会提示异常。请检查：
1. **可售房量**是否填错（应当是本店实际可供出租的房间数，不是全部房间数）
2. **出租间夜数**是否多填（可能把钟点房、免费房也计入了）

### Q5：日报提交后还能修改吗？

- **已提交（待审核）**：可以在审核列表中撤回重填
- **已锁定（审核通过）**：不能再修改，如需修改请联系管理员解锁

### Q6：投资人看不到某些门店的数据？

投资人只能看到与自己有**投资关系**的门店数据。如果投资人投资了门店A但只看到门店B，请联系管理员检查投资关系配置。

### Q7：日报中的数据是实时的吗？

日报数据由各门店店长每日手动填报，非系统自动抓取。数据的及时性和准确性依赖于门店的填报效率。

### Q8：CEO可以帮门店填报日报吗？

可以。CEO在日报管理页面可以切换到任意门店进行填报操作。
