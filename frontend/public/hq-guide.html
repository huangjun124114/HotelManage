林夕置业酒店管理系统 — 总部管理人员操作手册

适用于CEO/总部管理层，帮助您快速掌握系统全部经营分析功能

文档概述

适用角色

CEO 总部管理层

核心职责

  • 查看全部门店经营数据
  • 审核各门店日报
  • 利用经营分析功能进行经营决策

权限范围

能力说明
可以查看所有门店（9家）的经营数据
可以审核日报（通过/退回/锁定/解锁）
可以使用全部经营分析功能
可以帮门店填报日报
可以查看投资人列表
可以发送催报提醒（站内消息）
不能管理系统配置、用户管理、角色权限（管理员职责）
不能新增/编辑/删除门店
数据权限
CEO可查看旗下全部9家门店的数据，无任何数据隔离限制。

首页工作台（总部看板）

登录后默认进入总部看板，一目了然掌握全局经营状况。

筛选栏操作

  1. 选择基准日期（默认为今天）
  2. 选择门店范围（默认全部，可多选特定门店进行对比）
  3. 点击快捷按钮快速切换：今天 本周 本月
  4. 点击「查询」按钮刷新数据

看板内容解读

区域显示内容怎么看
统计卡片（8个） 应填报门店数、已填报、未填报、总营收、总间夜、均出租率、均ADR、均RevPAR 数字越大越好（未填报越少越好）
趋势对比图（6个） 营收 / 出租率 / ADR / RevPAR / 间夜 / 填报率 支持天/周/月切换；实线=当期，虚线=去年同期
门店排名 营收排名、出租率排名 谁好谁差一目了然，快速发现标杆和需关注门店
未填报列表 当天未填报门店清单 需要跟进催报，确保数据完整性
提示
统计卡片中的"均出租率""均ADR""均RevPAR"均为加权平均值，非简单算术平均。具体计算逻辑请参见 关键指标与计算逻辑。

日报管理

路径：日报管理

功能概述

日报管理整合了日报填报、查询、管理三大功能，是CEO查看和管理各门店日报的统一入口。

操作说明

  1. 按门店、日期范围、状态进行筛选
  2. 查看各门店日报列表，点击可查看详情
  3. CEO可以帮门店填报日报——切换到任意门店身份进行填报
CEO代填日报
当门店因特殊情况无法填报时，CEO可在日报管理中切换到该门店，代为填报。填报后同样需要审核流程。

日报审核

路径：日报审核   CEO重要职责

审核流程

流程说明
门店填报 → 提交（状态1：已提交）→ CEO审核 → 通过（锁定，状态2）/ 退回（状态3）

审核操作步骤

  1. 进入日报审核页面（默认显示「已提交」状态的日报）
  2. 查看日报详细数据，逐项核对
  3. 重点核对关键数据：房量、间夜、营收、出租率、ADR
  4. 做出审核决策：
    • 通过 → 日报锁定（状态2），门店不可修改
    • 退回 → 填写退回原因，门店需修改后重新提交

锁定与解锁

操作状态变化说明
锁定 已提交 → 已锁定 审核通过后自动锁定，门店不可修改
解锁 已锁定 → 已提交 特殊情况使用，解锁后门店可重新编辑
谨慎使用解锁
解锁已锁定的日报会让门店可以重新编辑数据。如非必要，请避免频繁解锁操作，以确保数据的稳定性和可追溯性。

退回流程

已提交（状态1）→ CEO退回 → 已退回（状态3）→ 门店编辑修改 → 重新提交 → 已提交（状态1）→ CEO再次审核
退回原因必填
退回日报时，必须填写退回原因，以便门店了解需要修改的具体问题。

未填报统计

路径：未填报统计

功能概述

快速了解当天各门店日报填报情况，并对未填报门店进行催报。

页面内容

区域内容
统计卡片 应填报门店数、已填报门店数、未填报门店数
未填报门店列表 门店名称、城市、区域、最近填报日期、店长、联系电话

催报操作

  1. 单店提醒：在未填报列表中，点击某门店行的「提醒」按钮，发送站内消息给该门店
  2. 一键提醒：点击页面顶部的「一键提醒」按钮，批量发送站内消息给所有未填报门店
催报效果
点击提醒后，系统会向目标门店的负责人发送站内催报消息。门店登录后即可看到提醒通知。

经营分析

经营分析是CEO最重要的决策支撑模块，包含6个子页面，覆盖全方位的经营数据视图。

总部看板

路径：经营分析 → 总部看板

功能与首页工作台完全一致，提供统计卡片、趋势对比图、门店排名和未填报列表。此处作为经营分析模块的统一入口。

路径：经营分析 → 门店日报表

功能说明

按日期和门店筛选，以表格形式展示每日经营明细数据。

默认显示列（8列）

列名说明
门店门店名称
日期日报日期
自有房量该门店可用房间数
间夜数当日出租间夜总量
散客间夜散客渠道的间夜数
出租率间夜数 ÷ 自有房量 × 100%

高级功能

  1. 自定义列：点击弹窗按钮，选择更多字段。字段按分组组织：基础、房量、指标、收入、扫码、好评、评分
  2. 分页控制：支持每页 20 / 50 / 100 条记录切换

门店月报表

路径：经营分析 → 门店月报表

功能说明

按月份和门店筛选，提供月度汇总数据，是月度经营分析的核心工具。

月报计算规则

字段类型汇总方式示例
金额/数量字段 SUM 求和 总营收、间夜数、散客间夜、钟点房费用等
比率指标 加权平均 出租率（以房量为权重）、ADR（以间夜为权重）、RevPAR（以房量为权重）
注意
月报中的出租率、ADR、RevPAR不是简单算术平均，而是加权平均。这意味着房量大的门店在汇总指标中权重更大，能更准确反映整体经营水平。

其他功能

  • 含合计行（后端返回），可直接查看全部门店月度汇总
  • 支持 Excel 导出

路径：经营分析 → 渠道分析

功能说明

分析各销售渠道的间夜贡献和收入，帮助CEO了解客源结构。

筛选操作

  1. 选择门店（支持多选）
  2. 选择日期范围
  3. 点击「查询」
  4. 可使用快捷日期按钮快速切换

可视化展示

  • 饼图：直观展示各渠道间夜占比
  • 表格：渠道名称、间夜数、占比、房费

13个渠道分类

分类渠道特点
直销 散客、外网 无佣金成本，利润最高
OTA 携程、同程艺龙、去哪儿、智行、美团酒店、飞猪 主流在线平台，需支付佣金
新媒体 抖音 短视频/直播渠道，新兴获客方式
民宿 小猪、途家、美团民宿 民宿平台渠道
其他 红色加力 分销/代理渠道

重点关注直销占比（散客+外网）。直销占比越高，渠道成本越低。如果OTA占比过高，可考虑加强自有渠道的营销投入。

关键指标与计算逻辑

深入理解系统各指标的计算方式，帮助CEO做出更精准的经营判断。

核心计算公式

间夜数 = 散客 + 携程 + 同程艺龙 + 去哪儿 + 智行 + 外网 + 美团酒店 + 飞猪 + 抖音 + 小猪 + 途家 + 美团民宿 + 红色加力 + 钟点房数量
13个渠道间夜之和 + 钟点房数量 = 当日总间夜数
出租率 = 间夜数 ÷ 自有房量 × 100%
反映当日房间的利用效率
ADR（平均房价）= 日租房房费 ÷ 间夜数
Average Daily Rate，反映平均每个出租房间的收入水平
总营收 = 日租房房费 + 钟点房费用 + 杂费
营收恒等式：total_revenue = daily_room_fee + hourly_room_fee + other_fee
RevPAR = 总营收 ÷ 自有房量
Revenue Per Available Room，综合衡量出租率和房价的收入指标

加权平均说明（总部看板）

重要
总部看板中的"均出租率""均ADR""均RevPAR"不是简单算术平均，而是加权平均，计算方式如下：
均出租率 = 总间夜数 ÷ 总自有房量
以各门店房量为权重，房量大的门店影响更大
均ADR = 总日租房费 ÷ 总间夜数
以各门店间夜数为权重
均RevPAR = 总营收 ÷ 总自有房量
以各门店房量为权重
为什么用加权平均？
不同门店房量差异较大（37间~65间），简单算术平均会让小店和大店权重相同，失真严重。加权平均能更准确反映整体经营水平。

月报汇总规则

字段类型汇总方式示例字段
金额/数量 SUM 求和 总营收、间夜数、散客间夜、钟点房费用、杂费等
比率指标 加权平均 出租率（房量权重）、ADR（间夜权重）、RevPAR（房量权重）
营收恒等式：total_revenue = daily_room_fee + hourly_room_fee + other_fee
无论日报还是月报，此等式始终成立，可用于数据校验

常见问题

Q: 首页看不到某些门店数据？

A: 请检查该门店是否处于启用状态。已停用的门店不会出现在首页看板的统计中。

Q: 趋势图没有去年同期数据？

A: 去年同期需要有填报数据才会显示对比线。如果去年某段时间没有填报，虚线部分会缺失。

Q: 可以帮门店填报日报吗？

A: 可以。在日报管理中，CEO可以切换到任意门店身份进行日报填报。

Q: 审核后还能修改吗？

A: 日报锁定后门店不可修改。如有特殊情况需要修改，CEO可先执行「解锁」操作，将状态恢复为已提交，门店即可重新编辑。

Q: 如何催报？

A: 进入「未填报统计」页面，可对单个门店点击「提醒」，或点击「一键提醒」批量发送催报消息给所有未填报门店。

Q: 数据导出格式是什么？

A: 系统导出为 Excel（.xlsx）格式，可用WPS或Microsoft Excel打开。

Q: 门店排名中的评分是怎么算的？

A: 取各渠道评分的算术平均值。评分为0或null的渠道不参与计算，确保结果公正。
