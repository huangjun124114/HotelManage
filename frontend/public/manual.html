林夕置业酒店经营日报管理系统

面向林夕置业旗下酒店门店的经营数据管理平台 —— 门店每日经营数据在线填报、总部实时监管、投资者便捷查看、自动化报表分析，一站式解决酒店经营数据管理需求。

⚙ 技术架构
前端框架 Vue 3.4 + Element Plus
后端框架 Spring Boot 2.7.18 + MyBatis-Plus
数据库 SQLite（轻量嵌入式存储）
部署方式 Docker 容器化部署
🌐 访问方式
生产环境 http://82.156.225.171
推荐浏览器 Chrome、Edge 最新版
最低分辨率 1280 × 720
