第一部分：角色概览

超级管理员（SUPER_ADMIN）与 CEO 是系统最高权限角色，负责系统初始化、用户管理、权限配置、门店管理、模板维护等全部操作。

管理员权限范围

  • 系统所有菜单可见、所有功能可操作
  • 门店的增删改查、启用/禁用
  • 用户的创建、编辑、角色分配、门店分配、密码重置
  • 角色的菜单权限配置
  • 投资人管理及投资关系配置
  • 日报模板与字段配置管理
  • 系统参数配置与操作日志查看
  • 日报的审核、锁定、解锁、退回

管理员操作流程总览

第二部分：逐步操作指南

2.1 门店管理

左侧菜单 → 门店管理 → 门店列表

新增门店

  1. 点击"新增"按钮

    进入门店新增表单页面

  2. 填写门店编码

    格式：城市拼音首字母 + 3位序号，例如 SZ001（深圳第1家门店）。重要 编码保存后不可修改。

  3. 填写基本信息

    门店名称、简称、所在城市、区域、自有房量、店长姓名、联系电话、开业日期

  4. 点击"保存"

    门店创建完成，默认状态为启用

编辑门店

  1. 在门店列表中点击"编辑"

    进入编辑表单，门店编码字段为灰色不可修改

  2. 修改需要更新的信息

    可修改名称、简称、城市、区域、房量、店长、联系电话、开业日期

  3. 点击"保存"

    修改即时生效

删除门店

  1. 在门店列表中点击"删除"

    系统将弹出确认对话框

  2. 确认删除

    系统执行逻辑删除（标记 deleted=1），数据不物理删除

若门店存在关联的日报数据、用户或投资人，系统将拒绝删除并提示"请先清理关联数据"。

状态切换

在门店列表中，使用 启用 / 禁用 Switch 开关，可快速切换门店营业状态。禁用后门店不出现在数据填报选择中。

查看团队

点击列表中"查看团队"按钮，弹窗显示该门店关联的所有用户列表，包含姓名、角色、手机号等信息。

创建用户账号（2.2 用户管理）

2.2 用户管理

左侧菜单 → 系统管理 → 用户管理

新增用户

  1. 点击"新增用户"按钮

    打开用户创建表单

  2. 填写基本信息

    姓名、手机号（手机号即为用户名）

  3. 选择用户类型

    1 - 管理员  2 - 门店  3 - 投资人

  4. 分配角色

    从角色列表中勾选一个或多个角色

  5. 选择所属门店

    勾选用户可管理的门店

  6. 点击"保存"

    系统自动创建账号，默认密码为 123456

编辑用户

  1. 点击用户列表中的"编辑"

    可修改姓名、手机号、用户类型

  2. 修改角色

    重新勾选角色分配

  3. 修改门店

    重新勾选所属门店

  4. 点击"保存"

    修改即时生效

重置密码

  1. 点击用户列表中的"重置密码"

    弹出确认对话框

  2. 确认重置

    密码重置为 123456，请通知用户及时修改

启用 / 禁用

在用户列表中切换状态开关。禁用后用户无法登录系统。

分配角色

  1. 点击"分配角色"

    弹出角色选择对话框

  2. 勾选一个或多个角色

    支持多角色叠加，权限取并集

  3. 点击"确定"

    角色分配即时生效

分配门店（数据权限）

  1. 点击"分配门店"

    弹出门店选择对话框

  2. 勾选用户可见的门店

    用户仅能查看和操作已勾选门店的数据

  3. 点击"确定"

    数据权限即时生效

2.4 投资人管理

左侧菜单 → 投资人管理

新增投资人

  1. 点击"新增投资人"

    打开投资人创建表单

  2. 填写投资人信息

    姓名、手机号等基本信息

  3. 点击"保存"

    系统自动执行以下操作：
      ① 创建 sys_user 账户（手机号为用户名，默认密码 123456）

投资关系配置

  1. 在投资人详情中点击"新增投资关系"

    打开投资关系配置表单

  2. 选择投资门店

    从门店列表中选择目标门店

  3. 填写投资信息

    投资金额（万元）、持股比例（%）、授权日期

  4. 点击"保存"

    系统同步创建 sys_user_store 关联记录，投资人获得该门店的数据查看权限

删除投资人

  1. 在投资人列表中点击"删除"

    弹出确认对话框

  2. 确认删除

    系统将级联删除：
      ① 投资人记录
      ② 关联的 sys_user 账户
      ③ 所有 sys_user_store 门店关联关系

级联删除不可恢复，请谨慎操作。

3.2 核心指标计算逻辑

公式1：间夜数

间夜数 = 散客 + 携程 + 同程 + 去哪儿 + 智行 + 外网 + 美团酒店 + 飞猪 + 抖音 + 小猪 + 途家 + 美团民宿 + 红色加力 + 钟点房数量
系统自动汇总12个渠道间夜数 + 钟点房数量，无需手动填写。

公式2：出租率

出租率 = 间夜数 / 自有房量 × 100 (%)
反映门店当日房间利用效率。出租率可超过100%（钟点房计入间夜时）。

公式3：ADR（平均房价）

ADR = 日租房房费 / 间夜数
Average Daily Rate，衡量每间售出房间的平均收入水平。间夜数为0时 ADR 为0。

公式4：RevPAR（每可用房收入）

RevPAR = 总营收 / 自有房量
Revenue Per Available Room，综合衡量出租率与房价的经营效率指标。

公式5：总营收

总营收 = 日租房房费 + 钟点房费用 + 杂费
系统自动汇总三项收入，无需手动填写。

3.4 数据权限隔离

系统根据用户角色自动过滤可见数据范围，确保数据安全。

角色数据范围实现逻辑
SUPER_ADMIN全部门店数据返回 null（不做门店过滤，查看全部）
CEO全部门店数据返回 null（不做门店过滤，查看全部）
门店用户仅绑定门店数据返回用户绑定的门店ID列表，SQL 中 WHERE store_id IN (...)
投资人仅投资关系门店数据返回投资关系表中的门店ID列表，SQL 中 WHERE store_id IN (...)

权限隔离执行流程

1. 用户发起请求 → 获取当前用户角色
2. 判断角色类型：
    • SUPER_ADMIN / CEO → 返回 null（不限制）
    • 门店用户 → 查询 sys_user_store 获取绑定门店列表
    • 投资人 → 查询投资关系表获取关联门店列表
3. 将门店列表注入 SQL 查询条件 → 返回过滤后的数据

3.5 投资人自动创建流程

自动创建流程技术说明

1. 管理员填写投资人信息并保存
2. 系统自动执行：
    • 创建 sys_user 记录（username=手机号, password=123456, user_type=3）
    • 创建 sys_user_role 记录，关联 INVESTOR 角色
3. 管理员配置投资关系（门店+金额+比例）：
    • 创建投资关系记录
    • 同步创建 sys_user_store 记录，投资人获得门店数据权限
4. 投资人登录后仅可见投资门店的经营数据

第四部分：常见问题 FAQ

如何批量导入历史数据？
进入 系统管理 → 数据导入，上传符合模板格式的 Excel 文件。系统会自动校验数据格式并批量导入日报记录。建议导入前先备份数据。
门店删除失败怎么办？
删除失败是因为门店存在关联数据（日报记录、用户或投资人）。需要先清理关联数据：
1. 检查并转移该门店下的日报数据
2. 解除用户与该门店的关联
3. 删除该门店的投资人关系
4. 再次尝试删除门店
用户忘记密码怎么办？
进入 系统管理 → 用户管理，找到目标用户，点击"重置密码"按钮。密码将重置为 123456，请通知用户登录后及时修改密码。
投资人登录看不到数据？
请检查以下配置：
1. 确认投资人是否已配置投资关系（投资人管理 → 投资关系）
2. 确认 sys_user_store 表中是否有该投资人与门店的关联记录
3. 确认投资人账户状态是否为"启用"
4. 确认 INVESTOR 角色是否具有"日报查看"菜单权限
如何查看系统操作记录？
进入 系统管理 → 操作日志，可按操作人、时间范围、操作类型筛选。所有登录、增删改操作均自动记录，包含操作人、时间、类型、IP等完整审计信息。
日报提交后发现数据错误如何处理？
根据日报状态采取不同操作：
• 已提交：管理员退回日报，填报人修改后重新提交
• 已锁定：管理员先解锁，再退回修改
操作路径：日报管理 → 选择日报 → 退回/解锁
