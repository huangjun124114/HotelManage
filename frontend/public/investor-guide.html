投资人操作指南

林夕置业酒店经营日报管理系统 · 版本 V1.0 · 2026-05-24

一、角色概览

作为投资人/股东，您可以通过本系统查看所投资门店的经营数据，了解营收、出租率、渠道分布等关键指标，辅助投资决策。

投资人角色要点

  • 身份：投资人 / 股东
  • 核心能力：查看投资门店的经营数据与分析报表
  • 数据范围：仅限与您有投资关系的门店
  • 权限限制：所有数据均为只读，不可填报日报、修改数据或管理用户/门店

权限与数据范围

能力项投资人权限
查看门店经营数据✓ 允许
查看经营分析报表✓ 允许

新增/编辑/删除门店✗ 不允许
管理用户账号✗ 不允许
管理投资人信息✗ 不允许

二、逐步操作指南

2.1 首页工作台（投资人视图）

登录系统后，首页将展示您所投资门店的经营概况。

查看投资门店列表

首页核心区域展示投资门店表格，包含以下字段：

字段说明
门店名称酒店门店全称
城市门店所在城市
今日营收当日营业总收入（元）
本月累计营收本月截至当日的累计营收（元）
今日出租率当日房间出租率（%）

查看门店经营趋势

点击门店对应行的"查看趋势"按钮，系统将弹出该门店的经营趋势折线图，直观展示近期营收、出租率等指标变化。

进入经营分析

通过首页快捷入口或左侧菜单进入"经营分析"模块，查看更详细的报表与数据分析。

2.2 查看门店列表

左侧菜单 → 门店列表

门店列表展示所有门店的基础信息（名称、城市、地址、房间数等）。

  • 可以浏览和查看所有门店基础信息
  • 不能新增、编辑或删除门店
  • 页面为纯只读模式

2.3 查看投资人列表

左侧菜单 → 投资人管理 → 投资人列表

投资人列表展示系统中投资人的基本信息（姓名、联系方式、投资门店等）。

  • 可查看投资人基本信息
  • 页面为纯只读模式，不可编辑

2.4 经营分析

经营分析是投资人最常用的核心模块，包含 6 个子功能，覆盖从总部全局到门店明细的多维度数据分析。

2.4.1 总部看板

经营分析 → 总部看板

总部看板提供所有投资门店的全局经营概览，适合快速掌握整体运营状况。

筛选条件：

  • 门店多选：下拉多选，仅显示您有投资关系的门店
  • 查询按钮：点击执行筛选查询
  • 快捷日期：一键选择本周 / 本月 / 本年

2.4.2 门店日报表

经营分析 → 门店日报表

门店日报表按门店和日期展示每日经营明细数据，是最细粒度的数据查看方式。

筛选条件：

  • 门店选择：选择要查看的门店
  • 日期范围：选择起止日期
  • 快捷日期：本周 / 本月 / 本年

默认显示 8 列：

列名说明
门店门店名称
日期营业日期
自有房量该门店可用房间总数
间夜数当日出租间夜总数
散客间夜散客渠道间夜数
出租率当日出租率（%）
总营收当日总营业收入（元）
RevPAR每间可用房收入

自定义列功能：

点击"自定义列"按钮，弹出字段选择弹窗，可从 7 个分类 中勾选需要显示的字段列，灵活定制报表视图。

数据导出：支持将当前筛选结果导出为 Excel 文件，点击"导出"按钮即可下载。

2.4.3 门店月报表

经营分析 → 门店月报表

门店月报表将日报数据按月汇总，便于从宏观角度审视门店经营表现。

筛选条件：

  • 门店选择：选择要查看的门店
  • 月份选择：选择目标月份

月报计算规则

  • 金额类 / 数量类：采用 SUM 求和（如总营收、间夜数）
  • 比率类（出租率 / ADR / RevPAR）：采用加权平均计算，非简单算术平均

数据导出：支持导出为 Excel 文件。

2.4.4 渠道分析

经营分析 → 渠道分析

渠道分析帮助您了解各获客渠道的贡献占比，优化渠道投入策略。

筛选条件：

  • 门店多选：选择一个或多个门店
  • 日期范围：选择起止日期
  • 快捷日期：本周 / 本月 / 本年

渠道间夜占比饼图：

直观展示各渠道的间夜数占比情况。

渠道明细表格：

列名说明
渠道名称渠道来源名称
间夜数该渠道贡献的间夜总数
占比该渠道间夜数占总间夜的百分比

主要渠道包括：携程、美团酒店、散客、同程艺龙、去哪儿、飞猪、小猪、智行等。

2.4.5 门店排名

经营分析 → 门店排名

门店排名帮助您在多个投资门店间进行横向对比，识别标杆和待改进门店。

排名维度：

  • 营收、出租率、间夜数、ADR、RevPAR、评分

时间维度：

  • 天 / 周 / 月

展示形式：

  • 横向柱状图：直观展示各门店排名对比
  • 排名明细表格：精确数值展示
  • 日期范围提示：页面顶部会显示实际查询的日期范围

2.4.6 经营趋势

经营分析 → 经营趋势

经营趋势模块提供多指标、多门店的时间序列对比分析。

功能特性：

  • 多指标折线图：营收 / 出租率 / 间夜数 / ADR
  • 多门店对比：可同时选择多个投资门店进行趋势对比
  • 时间维度：天 / 周 / 月
  • 默认范围：最近 30 天

三、业务逻辑详解

3.1 数据权限说明

数据权限规则

  • 投资人只能看到与自己有投资关系的门店数据
  • 所有数据为只读，不可修改、删除或填报
  • 如果看不到某个门店的数据，请联系管理员检查投资关系配置是否正确

3.2 核心指标计算逻辑

核心经营指标公式

  • 间夜数 = 各渠道间夜之和 + 钟点房数量
  • 出租率 = 间夜数 / 自有房量 × 100（%）
  • ADR = 日租房房费 / 间夜数
  • RevPAR = 总营收 / 自有房量
  • 总营收 = 日租房房费 + 钟点房费用 + 杂费

指标说明：

指标全称含义
ADRAverage Daily Rate平均每日房价，衡量客房定价水平
RevPARRevenue Per Available Room每间可用房收入，综合反映出租率与房价水平
间夜数Room Nights出租房间数 × 住宿夜数的总和

3.3 看板指标计算规则

汇总与平均规则

  • 均出租率 / 均 ADR / 均 RevPAR：采用加权平均（以间夜数或房量为权重），非简单算术平均
  • 同比对比：与去年同期数据对比，反映年度增长趋势
  • 月报汇总：金额类采用 SUM 求和，比率类采用加权平均

3.4 投资关系说明

投资关系决定了您在系统中的数据可见范围，由管理员在后台配置。

字段说明
投资金额您在该门店的投资总额
持股比例您在该门店的股权占比
授权起始日期数据查看权限的开始日期
授权截止日期数据查看权限的到期日期
可查看数据范围由管理员配置，可包括：收入数据、渠道数据、评分数据

如发现投资关系有误（如缺少门店或持股比例不正确），请联系系统管理员进行修正。

四、常见问题 FAQ

看不到某个门店的数据？
请检查您的投资关系配置是否正确。系统仅展示与您有投资关系的门店数据。如有疑问，请联系管理员核实。
数据是实时的吗？
不是。经营数据由各门店每日填报，非实时更新。通常当日数据在次日完成填报后可查看。
可以导出数据吗？
可以。门店日报表和门店月报表均支持Excel 导出，点击页面中的"导出"按钮即可下载。
忘记密码怎么办？
请联系系统管理员，管理员可将密码重置为默认密码 123456，登录后请及时修改。
能否修改数据？
不能。投资人角色为纯只读权限，所有数据均不可修改。如需数据修正，请联系门店管理员操作。
