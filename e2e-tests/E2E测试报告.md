## 三、发现并修复的Bug

### Bug #1: 经营趋势页面不自动加载数据
- **严重程度**: P1
- **现象**: 进入经营趋势页面时，图表区域空白（canvas未渲染），需手动点击"查询"才加载数据
- **根因**: `Trend.vue` 的 `onMounted` 只加载门店选项，未调用 `loadData()`
- **修复**: 在 `onMounted` 中添加 `await loadData()` 调用
- **文件**: `frontend/src/views/analysis/Trend.vue` 第138-142行
- **修复前**:
```javascript
onMounted(async () => {
  const res = await getStoreOptions()
  storeOptions.value = res.data || []
})
```
- **修复后**:
```javascript
onMounted(async () => {
  const res = await getStoreOptions()
  storeOptions.value = res.data || []
  // Auto-load trend data on mount with default date range
  await loadData()
})
```
